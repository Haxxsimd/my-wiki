# X370 Desktop

Current daily driver, running Debian 13. Built as a stopgap while the [[b550-build]] waits for
a CPU, and a clear upgrade over the [[desktop-x79|X79]], which is now a headless server.

## Specs

| Component | Details |
|---|---|
| Motherboard | MSI X370 |
| CPU | AMD Ryzen 5 1600 |
| GPU | MSI GTX 1060 6GB Gaming X (same model as the one in the [[desktop-x79|X79]]) |
| RAM | 16GB DDR4 Corsair |
| Storage | 500GB M.2 NVMe — the Debian 13 drive moved over from the X79 |
| PSU | EVGA 850W |
| OS | Debian 13 |
